# فيديو موشن: توصيل مجاني لأول طلب

فيديو إعلاني مدته 15 ثانية بنفس ستايل الصور الإعلانية (برتقالي وأسود وكريمي، خط Changa)، بحجمين:

| الملف | الاستخدام | المقاس |
| --- | --- | --- |
| `video/offer-story.mp4` | ريلز، ستوري، تيك توك | 1080 × 1920 |
| `video/offer-feed.mp4` | بوست فيسبوك وإنستغرام | 1080 × 1350 |
| `video/*-silent.mp4` | نفس الفيديو بدون صوت، إذا تريد تحط موسيقى من مكتبة إنستغرام أو ميتا | |
| `video/*-cover.png` | صورة الغلاف (آخر لقطة) للريلز أو كصورة مصغّرة للإعلان | |

## القصة

| الوقت | المشهد |
| --- | --- |
| 0 – 2 ثانية | المندوب يعبر الشاشة ويكشف "توصيل مجاني" وراه |
| 2 – 5 | "لأول طلب" وملصق "أجرة التوصيل: صفر" ينطبع بقوة، بعدين الكاميرا تغطس داخل حرف الصاد |
| 5 – 8 | خريطة: المسار يرتسم من المتجر لباب البيت، والطلب يوصل |
| 8 – 11 | المندوب يسوق قدام أفق بغداد: "داخل بغداد" و"لغاية نهاية الشهر" |
| 11 – 15 | البطاقة الأخيرة: الاسم، العرض، زر "اطلب هسه"، ورقم الهاتف |

كل النصوص ضمن المنطقة اللي ما تغطيها أزرار إنستغرام وفيسبوك بالريلز والستوري.

## الصوت

الموسيقى والمؤثرات مصنوعة بالكامل بالكود، يعني ما بيها حقوق لأي أحد: إيقاع مقسوم على دربكة، باص، لحن قصير على مقام الحجاز، ومؤثرات متزامنة مع الحركة (صوت مرور المندوب، ضربة الملصق، رنة وصول الطلب). مستوى الصوت مضبوط على ‎-14 LUFS، وهو المستوى المعتاد بإنستغرام وتيك توك.

إذا تفضّل موسيقى ترند، استخدم النسخة بدون صوت وأضف الموسيقى من داخل إنستغرام، أو من خيار "إضافة موسيقى" بمدير إعلانات ميتا.

## تغيير الاسم والرقم والألوان

الاسم "التوصيل السريع" والرقم "0770 000 0000" مؤقتين. كل شي موجود بملف `offer.html`:

1. **الاسم:** موجود بمكانين (أول مشهد والبطاقة الأخيرة). ابحث عن "التوصيل السريع" واستبدله.
2. **الرقم:** ابحث عن "0770 000 0000" واستبدله.
3. **الألوان:** بأعلى الملف:
   ```css
   --brand: #F04E23;  /* البرتقالي */
   --ink: #111111;    /* الأسود */
   --bg: #F3EDE0;     /* الكريمي */
   ```
4. **أعد التصدير:**
   ```bash
   npm run motion:render
   ```

التصدير يحتاج متصفح Google Chrome وبرنامج ffmpeg على الجهاز، وياخذ تقريباً 3 دقايق لكل حجم. إذا ما عندك ffmpeg:

- **ويندوز:** `winget install Gyan.FFmpeg`
- **ماك:** `brew install ffmpeg`

## أوامر مفيدة

```bash
# حجم واحد بس
node scripts/render-motion.cjs design/motion/offer.html --format story

# معاينة لقطات معينة كصور (بالثواني) بدون تصدير فيديو
node scripts/render-motion.cjs design/motion/offer.html --stills 0,3,7.5,14.9

# بدون صوت
node scripts/render-motion.cjs design/motion/offer.html --no-audio
```

تگدر تفتح `offer.html?t=3.2` بالمتصفح حتى تشوف أي لحظة من الفيديو كصورة ثابتة.

## شلون ينصنع

`offer.html` بيه كل المشاهد ومحرك حركة صغير: الدالة `render(t)` ترسم اللقطة بأي وقت بالضبط. سكربت التصدير يصوّر كل إطار بكروم. كل إطار من الثلاثين بالثانية هو معدّل عشر لقطات قريبة، وهذا يعطي ضبابية حركة طبيعية للأشياء السريعة. بعدها ffmpeg يجمعهم مع الصوت بملف MP4 بصيغة H.264.
