# الصور الإعلانية

مجموعة إعلانات جاهزة للنشر لشركة التوصيل، بنظام بصري واحد: برتقالي وأسود وكريمي، خط Changa للعناوين وCairo للنصوص، شريط أسود بأسفل كل صورة بيه زر الطلب ورقم الهاتف، وخط أفق بغداد خفيف.

كل إعلان بحجمين:

| الملف | الاستخدام | المقاس |
| --- | --- | --- |
| `*-square.png` | بوست فيسبوك وإنستغرام | 1080 × 1080 |
| `*-story.png` | ستوري وريلز | 1080 × 1920 |

| الإعلان | العنوان | الهدف |
| --- | --- | --- |
| `offer` | توصيل مجاني لأول طلب | جذب زبائن جدد |
| `app` | اطلب من التطبيق وتابع المندوب لحظة بلحظة | تحميل التطبيق |
| `hiring` | نحتاج مناديب توصيل | توظيف مناديب |
| `merchants` | عندك متجر أونلاين؟ خلي التوصيل علينا | تعاقد مع التجار |

ملفات الستوري مصممة بحيث النصوص بعيدة عن أعلى 250 بكسل وأسفل 340 بكسل، وهي المناطق اللي تغطيها أزرار إنستغرام وفيسبوك.

## الاسم والرقم مؤقتين

الاسم "التوصيل السريع" والرقم "0770 000 0000" مجرد مكان محجوز. حتى تحط اسمك ورقمك:

1. افتح ملفات `.html` بأي محرر نصوص واستبدل النصين بالاسم والرقم الحقيقيين (بحث واستبدال على كل الملفات).
2. غيّر الألوان إذا تريد من المتغيرات بأعلى كل ملف:
   ```css
   --brand: #F04E23;      /* اللون الأساسي */
   --brand-ink: #111111;  /* الأسود */
   --accent: #F04E23;     /* لون الزر */
   --bg: #F3EDE0;         /* الكريمي */
   --fg: #111111;         /* لون النص */
   ```
3. أعد تصدير الصور:
   ```bash
   npm run ads:render
   ```
   الأمر يستخدم متصفح Google Chrome الموجود على جهازك ويكتب ملفات PNG جديدة بجانب كل HTML، ويحذرك إذا طلع نص خارج حدود الصورة. إذا كروم بمكان غير اعتيادي ضع مساره بالمتغير `CHROME_PATH`.

نفس الطريقة لتغيير أي نص: العنوان، السطر الداعم، العرض، أو المدينة.

## اتجاهات بديلة

قبل اختيار هذا الاتجاه، انصممت خمسة اتجاهات مختلفة لنفس الإعلان وتم تقييمها من ثلاث زوايا: جذب الانتباه بالفيد العراقي، جودة الخط العربي والتصميم، ووضوح القراءة على الموبايل. الصور بمجلد `concepts/`:

| الملف | الاتجاه |
| --- | --- |
| `bold-blocks.png` | كتل لونية جريئة وعنوان ضخم (المختار) |
| `playful-rounded.png` | أزرق مرح مع ملصق دائري، للجمهور الشاب |
| `night-city.png` | بغداد بالليل، كحلي وذهبي، طابع فخم |
| `warm-paper.png` | ورق دافئ ورسم مندوب بلونين، طابع محلي |
| `route-map.png` | خريطة ومسار توصيل، طابع تقني |

أي اتجاه منها ممكن ينسحب على كل المجموعة إذا تفضله.
