# مساعد الدليفري

لوحة تحكم عربية لمدير شركة توصيل في العراق. تختصر ثلاث شغلات تاخذ أغلب الوقت:

1. **مراقبة الحملات الإعلانية.** تسجّل أو تستورد أرقام الحملات، والتطبيق يگلك لكل حملة: أوقفها، راقبها، استمر، أو كبّرها، مع السبب والخطوة الجاية. وتگدر تطلب تحليل كامل من الذكاء الاصطناعي.
2. **الرد على الرسائل.** تلصق رسالة الزبون من واتساب أو فيسبوك أو إنستغرام، والمساعد يكتب رد احترافي باللهجة العراقية حسب معلومات شركتك وأسعارك. تراجعه، تنسخه، أو تفتحه بالواتساب مباشرة.
3. **النشر المستمر.** يكتب منشور جاهز لأي منصة، أو خطة نشر كاملة لأسبوع، وكل منشور بتاريخه.

يشتغل على **نموذجك المحلي** (Ollama أو LM Studio) أو على **Claude**. البيانات تنحفظ بملف واحد على جهازك.

## التشغيل

تحتاج Node.js نسخة 20 أو أحدث.

```bash
npm install
cp .env.example .env.local
npm run build
npm start
```

افتح http://localhost:3000.

للتطوير استخدم `npm run dev` بدل الأمرين الأخيرين.

### ربط النموذج المحلي

مثال بـ Ollama:

```bash
ollama pull qwen2.5:7b
ollama serve
```

بعدين من صفحة **الإعدادات** اختار "النموذج المحلي"، اكتب العنوان واسم النموذج، واضغط **جرّب الاتصال**.

| الخادم | العنوان |
| --- | --- |
| Ollama | `http://localhost:11434/v1` |
| LM Studio | `http://localhost:1234/v1` |

أي خادم يدعم واجهة `/v1/chat/completions` يشتغل. النماذج الأكبر تكتب عربي ولهجة عراقية أحسن. إذا الردود ضعيفة جرّب نموذج أكبر.

### استخدام Claude بدل النموذج المحلي

ضع المفتاح بملف `.env.local` وأعد تشغيل التطبيق:

```bash
ANTHROPIC_API_KEY=sk-ant-...
```

بعدين اختار Claude من الإعدادات. النموذج الافتراضي `claude-opus-5`. التطبيق يفعّل التحويل التلقائي لنموذج بديل إذا Claude اعتذر عن طلب.

### الفتح من الموبايل

شغّل التطبيق على كل الشبكة:

```bash
npm start -- -H 0.0.0.0
```

وافتح `http://IP-الكمبيوتر:3000` من موبايلك على نفس الواي فاي. إذا راح تفتحه خارج البيت أو الشركة، ضع كلمة سر:

```bash
APP_USER=admin
APP_PASSWORD=كلمة-سر-قوية
```

## أول خطوات

1. **الإعدادات:** اكتب اسم الشركة، المناطق، أسعار التوصيل، وأوقات الدوام. أضف الأسئلة المتكررة وأجوبتها. المساعد يعتمد عليها وما يخترع أسعار.
2. **قواعد الحملات:** حط الكلفة المستهدفة لكل نتيجة حسب هامش ربحك. مثلاً إذا الطلب يربحك 2,000 دينار، لا تخلي كلفة الطلب من الإعلان أكثر من هذا.
3. جرّب بزر **أضف بيانات تجريبية** حتى تشوف كل شي شلون يشتغل، وبعدين احذفها وأضف حملاتك.

## شلون يحكم على الحملات

كل حملة تنقارن آخر 7 أيام منها (تتغير من الإعدادات) بالسبعة اللي قبلها:

| التوصية | متى تطلع |
| --- | --- |
| أوقفها | صرفت ضعف كلفة النتيجة المستهدفة بدون ولا نتيجة، أو الكلفة أعلى من الهدف بـ 50% |
| راقبها | الكلفة فوق الهدف، أو زادت أكثر من 30% عن الأسبوع اللي قبله، أو نسبة النقر أقل من 0.8% |
| كبّرها | الكلفة أقل من الهدف بـ 20% مع 5 نتائج على الأقل وبدون تراجع |
| استمر | ضمن الهدف |
| بيانات قليلة | الصرف بعده أقل من الحد الأدنى للحكم |

كل هذي الأرقام تتعدل من صفحة الإعدادات. زر **حلل بالذكاء الاصطناعي** يقرأ الأرقام اليومية ويكتب خطوات عملية ونصيحة لتوزيع الميزانية.

### استيراد الأرقام من مدير الإعلانات

من مدير إعلانات ميتا: التقارير، ثم التقسيم حسب الوقت **اليوم**، ثم تصدير CSV. التطبيق يتعرف على الأعمدة بالعربي والإنكليزي (اسم الحملة، اليوم، المبلغ المنفق، مرات الظهور، النقرات، النتائج). إذا نفس اليوم مستورد من قبل، الأرقام الجديدة تحل محله. يوجد قالب جاهز للتحميل من صفحة الحملات.

## استقبال الرسائل تلقائياً (اختياري)

إذا عندك تطبيق Meta للمطورين، تگدر تخلي رسائل الواتساب والماسنجر والإنستغرام توصل للتطبيق لحالها ويكون ردها جاهز للمراجعة. التطبيق **ما يرسل أي رد لحاله**؛ أنت تراجع وترسل.

1. ضع هذي القيم بـ `.env.local`:
   ```bash
   META_VERIFY_TOKEN=أي-نص-سري-تختاره
   META_APP_SECRET=من-إعدادات-تطبيق-Meta
   ```
2. التطبيق لازم يكون على رابط عام https.
3. بإعدادات Webhooks بتطبيق Meta حط الرابط `https://موقعك/api/webhooks/meta` ونفس الـ Verify Token.
4. اشترك بحقل `messages` لـ WhatsApp Business Account، وحقول الرسائل للصفحة وحساب إنستغرام.

## البيانات

كل شي ينحفظ بـ `data/db.json`. للنسخ الاحتياطي انسخ هذا الملف. تگدر تغيّر مكانه بـ `DATA_DIR`.

## للمطورين

| المسار | المحتوى |
| --- | --- |
| `src/lib/ai.ts` | الاتصال بالنموذج المحلي و Claude، والتحقق من صيغة JSON |
| `src/lib/assistant.ts` | التعليمات (prompts) لكل ميزة |
| `src/lib/evaluate.ts` | قواعد الحكم على الحملات |
| `src/lib/db.ts` | التخزين بملف JSON مع كتابة آمنة |
| `src/app/api/` | واجهات API لكل الميزات والـ Webhook |

```bash
npm run lint
npm run typecheck
```

### أفكار للمرحلة الجاية

- سحب أرقام الحملات تلقائياً من Meta Marketing API بدل الاستيراد.
- إرسال الردود من داخل التطبيق عبر WhatsApp Cloud API بعد الموافقة عليها.
- نشر المنشورات المجدولة تلقائياً على فيسبوك وإنستغرام.
